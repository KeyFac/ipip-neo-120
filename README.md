# IPIP-NEO-120

大五人格问卷的中文网页版。120 条陈述，测量神经质、外向性、开放性、宜人性、尽责性五个维度，
以及每个维度下的六个层面（共 30 个）。

纯静态站点，无后端、无依赖、无构建步骤。作答与计分全部在浏览器本地完成。

## 本地运行

不需要安装任何东西。因为站点使用相对路径加载资源，直接双击 `index.html` 即可，
或者起一个静态服务器：

```powershell
python -m http.server 8000 --directory .
```

然后打开 http://localhost:8000 。

## 目录结构

```
index.html          页面结构（介绍 / 作答 / 结果三个视图）
assets/style.css    样式
assets/app.js       作答流程、计分、结果渲染、导出
assets/data.js      量表数据，每条都带 zh / en（自动生成，勿手改）
assets/i18n.js      界面文案，zh / en 两套
assets/favicon.svg  图标
.nojekyll           让 GitHub Pages 跳过 Jekyll 处理
```

## 数据来源

英文条目出自 **Johnson (2014)** 的 120 题 IPIP-NEO-PI-R，题目本身取自
[International Personality Item Pool](https://ipip.ori.org/)（公共领域）。
结构、键向（55 条反向计分）、维度与层面的归属，与原始量表一致。

`assets/data.js` 由构建脚本从上游条目数据合并生成，生成时会校验：

- 条目总数为 120
- 30 个层面各 4 条
- 每个层面都能在元数据里找到
- 每条陈述都有对应的中文译句

## 关于中文

**中文译句由本项目自行翻译，不是经过信效度检验的正式中文版量表。**

社区的公开中文版本大量使用四字成语（例如把 "Find it difficult to approach others"
译成「善察言观色」，把 "Boast about my virtues" 译成「有良好的道德感」），
语义偏离且褒贬颠倒，会直接污染作答。本项目按以下原则重译：

- 第一人称、口语化，保持原条目的行为指向
- 不用成语、不用带褒贬的评价性词汇
- 反向条目在中文里也保持"反向"——不额外加否定词

如果你需要临床、科研或任何有常模的正式评估，请使用经过本地化验证的专业版本。

## 中英切换

右上角 `中文 / EN` 是整站切换，不是只换题面：

- 界面文案（按钮、说明、提示、导出文本）在 `assets/i18n.js`
- 题目、维度名、层面名、全部解读文字在 `assets/data.js`，每条都是 `{ zh, en }`
- 题面下方始终显示另一种语言作为对照，跟着当前语言自动对调
- 切换后端会重写 `<html lang>`，英文版自动换成拉丁字体优先的字体栈
  （否则中文标点字体会把 `’ “ ”` 渲染成全角，字距被撑开）
- 选择存在 `localStorage`，刷新后保持；结果页切换语言时，已展开的层面保持展开

英文解读不是中文的逐字直译，是按英文语感重写的，人称和语气与中文版一致。

## 计分

五点量表（1–5）。反向条目按 `6 - 原始作答` 翻转后累加：

| 层级 | 构成 | 原始分范围 | 换算 |
|---|---|---|---|
| 层面 | 4 条 | 4–20 | `(raw - 4) / 16 × 100` |
| 维度 | 24 条 | 24–120 | `(raw - 24) / 96 × 100` |

维度分档：<20 很低、<40 偏低、<60 中等、<80 偏高、≥80 很高。
层面分档：<33.4 低、>66.6 高、其余为中。

**0–100 是量表区间的线性换算，不是人群百分位。** 没有常模数据，本项目不会给出
"你比百分之多少人高"这类结论。

## 隐私

站点不发起任何网络请求。作答进度存在 `localStorage`，结果可以通过 `#r=`
后面的 120 位数字编码在链接里分享——只有拿到链接的人能看到那份结果。
